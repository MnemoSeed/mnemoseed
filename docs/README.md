# MnemoSeed Documentation

- `docs/design/`, `docs/prd/`, `docs/REFERENCES.md` — **English canonical docs**. They are synced from the Chinese working tree before every merge to `main` / release.
- `docs/zh/` — Chinese working tree. Day-to-day design and PRD updates land here first; the English tree follows at sync points.

If a file exists only under `docs/zh/`, the English version has not been synced yet.
