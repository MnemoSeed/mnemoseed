# 04 · 认知分级隔离、Persona 解耦与零知识隐私

---

## 1. 认知分级隔离（Cognitive Grading Isolation）

**问题**：多模型混用时代，"笨模型"的幻觉会污染"聪明模型"积累的经验资产。

**模型分层**（示例，可在 `.env` 配置）：

| Tier | 代表 | 权限 |
|---|---|---|
| Tier 1 | Claude 5 Sonnet、GPT-5.6、本地 Llama-3.3-70B | 读全库；提炼物写主基座 |
| Tier 2 | 中端模型 | 读全库；提炼物进待复核队列 |
| Tier 3 | 轻量端侧模型（GPT-mini 类、本地小模型） | 读全库；提炼物**只写**隔离图谱 |

```mermaid
flowchart LR
    subgraph Read["读路径（向下兼容 · 单向继承）"]
        T3R["Tier 3 模型"] -->|"可读继承"| T1G[("Tier_1_Core_Graph")]
    end
    subgraph Write["写路径（物理隔离 · 防反向污染）"]
        T3W["Tier 3 对话"] -->|"提炼物锁死"| T3G[("Tier_3_Isolated_Graph")]
        T3G -.->|"唯一上升通道:<br/>Tier 1 高认知二次反思"| T1G
        T1W["Tier 1 对话"] -->|"提纯直写"| T1G
    end
```

**钢印是隔离的前提**：每条写入必须在 MCP 拦截时打上 `cognitive_tier` + `model_id`，事后不可篡改（进入 provenance.history）。

## 2. Persona 与经验基座解耦

**问题**：用户给不同 Agent 躯体配不同 System Prompt（傲娇助理 / 严谨法务）。语气与人设词若沉淀进记忆，换面具即污染。

**解**：梦境引擎反思时外挂 De-biasing Protocol：
- 三元组提取只保留 `User → Habits → Patterns` 硬事实；
- 语气/情绪/角色词剥入 `persona_style` 侧表（按 `persona_id` 索引）；
- 经验基座与人格面具 1:N 关系——**一套记忆，千面面具**。

```mermaid
flowchart TB
    Base[("经验基座<br/>Tier_1_Core_Graph<br/>(纯净事实与偏好)")]
    P1["Persona: 傲娇开发助理"]
    P2["Persona: 严谨法务"]
    P3["Persona: 生活管家"]
    Base --> P1 & P2 & P3
    P1 -.->|"语气风格侧表<br/>不回写基座"| PS[("persona_style 侧表")]
    P2 -.-> PS
    P3 -.-> PS
```

## 3. 零知识隐私矩阵

**问题**：记忆包含用户最深度的偏好、商业机密、情感资产。云端记忆若无物理级隔离，B 端与高净值用户无法建立信任。

**双轨模式**：

```mermaid
flowchart TB
    subgraph Track1["轨 ① BYOK 本地加密（自托管/免费）"]
        D1["明文记忆"] -->|"客户端私钥派生加密<br/>(密钥永不出设备)"| E1["密文 blob"]
        E1 --> S1["云端存储桶<br/>(仅存随机密文)"]
    end
    subgraph Track2["轨 ② TEE 机密计算（商业 SaaS）"]
        D2["明文记忆"] -->|"E2EE 传输"| NE["AWS Nitro Enclave<br/>(硬件安全黑盒)"]
        NE -->|"黑盒内短暂解密<br/>执行梦境提炼"| R2["提炼结果加密回传"]
        NE -.->|"平台管理员/我方团队<br/>物理不可见明文"| X["❌"]
    end
```

**信任边界规则**：
1. 云端任何组件不持久化明文；
2. Enclave attestation（远程证明）向客户端开放验证接口——用户可密码学验证"跑的是未篡改的 MnemoSeed 代码"；
3. Provenance 字段同样加密存储，审计在客户端本地完成。

## 4. 合规基线

- 官方企业渠道接入（AWS Bedrock / Google Vertex AI），拒绝无 DPA 承诺的 API 中介（如 OpenRouter）——杜绝中间人泄露面；
- 仅选用支持 **ZDR（Zero-Data-Retention）** 的模型端点；
- 目标合规：GDPR / CCPA / 马来西亚 PDPA。
