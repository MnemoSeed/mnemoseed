# 05 · 业界对标与精华提取

> 分析对象：N01ennn《How to be a Memory Engineer》(X, 2026-08-03，汇总 Stanford / Microsoft / Anthropic / Nvidia 四个实验室视角)、Claude-Mem、MemPalace、Mem0、Letta/MemGPT。
> 原则：**所有借鉴必须以脑神经科学/人类心理学理论为推导起点**，工程概念只是证据，不是公理。

---

## 1. N01ennn 四透镜文章：全文拆解与取舍

原文核心论点：*"你的 Agent 的问题不是它会遗忘，而是它从不刻意遗忘。"* 记忆工程师优化的不是"记住什么"，而是"放下什么"。

### 透镜一：Stanford —— 记住的代价（成本视角）

| 原文发现 | 我们的映射 | 采纳动作 |
|---|---|---|
| 真实成本不在查询侧，在**写入路径**（write path/construction） | 正是我们"两道脱水阀"存在的理由 | ✅ 已覆盖（Stripper + Delta 打桩）。**补**：把 "cost per correct answer" 列为一级指标进 NFR |
| 同精度两个系统能耗差 **47 倍**；accuracy 隐藏账单 | 营销与工程双料弹药 | ✅ 写入推广计划。原始论文已一手核实（arXiv:2606.06448，见 REFERENCES I2a） |
| 记忆系统四家族：raw context / flat retrieval / structured extraction / fully agentic，**没有全能冠军，只有刻意选择付哪种成本** | 我们是 structured extraction 家族 | ✅ 白皮书定位语更新：不声称"最好"，声称"刻意选择" |

### 透镜二：Microsoft —— 什么值得留（内容视角）

| 原文发现 | 神经科学依据 | 采纳动作 |
|---|---|---|
| PlugMem：存 **facts 和 skills**，不存 logs；更多原始记忆反而让 Agent 变差 | 情节记忆→语义记忆转化（Tulving）：人脑不 replay 事件，只保留提炼出的事实与技能 | ✅ 已覆盖（三元组 + SKILL_SEQUENCE 肌肉记忆）——原始论文一手核实（arXiv:2603.03296，见 REFERENCES I2b） |
| 效用指标：**每个 token 送达多少决策相关信息**，密度胜过体积 | 工作记忆容量上限（Miller 7±2 的现代修正版 ≈ 4 块） | ✅ 已覆盖（top-k ≤ 5 抗稀释）——理论锚点补强 |
| Memento：模型自己写 dense note 后删掉原始推理；**遗忘≠删除**，被擦除的推理在模型内留有"影子" | 记忆痕迹理论：遗忘是提取失败而非痕迹消失 | ⚠️ **原始论文未能在 arXiv 定位**（REFERENCES I2c）——"遗忘≠删除"的结论由记忆痕迹理论独立支撑，保留；具体数字（2–3x、15 分）弃用 |

### 透镜三：Anthropic —— 谁控制它留什么（控制权视角）

| 原文发现 | 采纳动作 |
|---|---|
| 记忆放在**可打开、可编辑、可删除的文件/存储**里；打不开的存储 = 你不拥有的存储 | ⚠️ **我们的缺口**。补：`memory.export`（全量导出为可读格式）+ `memory.forget_this`（用户显式删除权）进 PRD-03/04——这也是 GDPR 被遗忘权的合规刚需 |
| scope（谁读谁写）、audit trail、rollback | ✅ 已覆盖（Tier 写保护 + provenance.history + 版本链回滚）。⚠️ "首遍错误率降 97%"为产品文档转述，未独立核实（REFERENCES I2d） |
| 错误记忆不是失败一次，而是**持续污染此后每个 session** | ✅ 这是我们 Reconcile 红线规则的量化论据 |

### 透镜四：Nvidia —— 硬件落点（系统视角）

| 原文发现 | 采纳动作 |
|---|---|
| 一切记忆决策最终落在 KV cache / HBM 带宽上；全量历史进 context 是**平方级**代价 | ✅ 营销弹药：长上下文方案在物理层就输了 |
| construction 是纯 prefill 型负载，**必须当后台批处理任务**：限速、批量化、延迟到空闲期，绝不挡在延迟敏感路径上 | ✅ 已覆盖（idle 5s 触发 + 异步做梦）——Nvidia 视角独立验证我们的调度决策 |

### 原文第 13/15 步：构建顺序（直接采纳为开发纪律）

> "在调度任何自动化之前，先手动跑一遍。如果输出不能真正改变决策，就不配拥有调度。"

✅ **采纳**：PRD-02 增加 `dream --once` 手动巩固 CLI——M1 阶段先手动跑梦境验证提炼质量，自动化触发器 M1 末才打开。防止"系统在三条笔记上幻觉出不存在的关联，然后训练你忽略它"。

### 原文对我们的唯一一处修正

> "Never auto-merge contradictions: two memories that disagree may both have been right in different contexts."

我们 v4.0 初稿在"时间戳明确/来源权威度差足够大"时允许自动裁决。原文提醒了一个我们漏掉的情形：**两条矛盾记忆可能在不同上下文里都对**（"Go 用 tabs" vs "Python 用 spaces"——不是冲突，是作用域不同）。

✅ **采纳为 Reconcile 第三分支：情境作用域共存（Context-Scoped Coexistence）**——先用 cues 尝试消解冲突：若矛盾双方能被项目/场景/时间 cues 划清各自作用域，则不是冲突，是两条带不同适用条件的记忆，各自标注 scope 共存；cues 无法划界时才走裁决/flag_conflict。神经科学依据：**情境依赖记忆**（context-dependent memory, Godden & Baddeley 1975）——记忆本来就绑定提取情境，全局唯一的"事实"才是工程幻觉。

## 2. Claude-Mem 拆解

**它是什么**：Claude Code 插件，hook 驱动——session 中自动捕获 tool 调用观察（observations），AI 压缩成语义摘要，下个 session 自动注入。Apache-2.0，多 host（Claude Code / Codex / Gemini / Copilot…）。

**值得借的**：

| 概念 | 神经科学依据 | 采纳动作 |
|---|---|---|
| **Host 生命周期 hook 零摩擦捕获**（SessionStart 注入 / 运行中观察 / 压缩入库）——用户零操作 | 编码的自动化：海马体编码不需要意识努力（automatic encoding） | ✅ 我们的 MCP 拦截器本质相同，但**补**：SessionStart 时主动注入"上周记忆摘要"作为开场上下文（冷启动暖场），而不只是被动等 recall |
| **渐进式压缩阶梯**（raw → observation → summary 多级） | 记忆的多级表征：情节 → 语义 → 图式（schema） | ⚠️ 部分采纳：我们已有 raw 分片 → 三元组两级；**不采纳**中间级——多级摘要会累积失真（每次摘要都是一次有损压缩，传话游戏效应） |

**它的盲区（我们的攻击面）**：无冲突调和、无衰减、摘要式扁平存储、无图谱因果、无认知分级——属于"flat retrieval + 摘要"家族，四个透镜只做了"存"一个。

## 3. MemPalace 拆解（我们日常在用的系统，最有资格细评）

**它是什么**：以"记忆宫殿（method of loci）"为原型的本地记忆系统——wing/room/drawer 空间组织，**逐字存储（verbatim，永不摘要）**，写入时语义去重（相似度 0.9 阈值），时序知识图谱（valid_from/valid_to + invalidate），hallways（实体共现关联）/tunnels（跨域联想），sync 清理源已删除的抽屉。

**值得借的**：

| 概念 | 神经科学依据 | 采纳动作 |
|---|---|---|
| **逐字优先，派生其次**：原文永不摘要，派生事实单独进 KG——有损操作只允许发生在派生层 | 记忆再现实验：人对逐字（verbatim）与要义（gist）是**双通道并行存储**（Fuzzy-Trace Theory, Brainerd & Reyna），要义提取不擦除原文 | ✅ 已覆盖（LanceDB 原始分片 + 图谱三元组双轨）——Fuzzy-Trace Theory 给了我们理论命名 |
| **写入时语义去重**（check_duplicate，相似则拒写） | 赫布定律（Hebbian）：重复激活的突触被强化，而不是复制一个新突触 | ✅ **采纳进 Capture**：捕获前做近重复检查，命中已有记忆则 `last_reinforced` 回弹 +1，不产生新分片——**强化发生在编码时，不等做梦** |
| **时序 KG**：invalidate 而非 delete，valid_from/valid_to | 再巩固——旧痕迹保留为历史版本 | ✅ 已覆盖（版本链）——独立验证 |
| **hallways/tunnels 关联遍历**：实体共现与跨域联想检索 | 扩散激活（spreading activation, Collins & Loftus）：想起一个概念会激活邻近概念 | ⚠️ **轻量采纳**：图谱 2-hop 遍历已有扩散激活的影子；加**共现边**（两记忆在同一 session 被激活则边权 +1）作为检索时的次级排序信号——纯向量相似度抓不到"经常一起被想起" |
| **sync 源衰减**：源文件消失的记忆自动降级 | 记忆与来源共存亡（来源监控的物理版） | ✅ 采纳进 Decay：`provenance.source` 失效（如引用的 session 被删）的记忆自动降权 |
| **记忆宫殿空间隐喻本身** | 位置细胞/认知地图（O'Keefe；Tolman）：空间是人类记忆最古老的索引结构 | ❌ 不采纳 wing/room 命名空间——我们的索引是语义+情境 cues，空间隐喻对个人助理友好、对代码记忆是多余的间接层 |
